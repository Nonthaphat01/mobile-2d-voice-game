# บ้านและเหมือง · 2D Multiplayer

แตก ZIP ให้ครบแล้วเปิด `index.html` ในเบราว์เซอร์เพื่อเล่นคนเดียว เก็บไฟล์ JavaScript และโฟลเดอร์ `assets` ไว้ข้าง `index.html` ตามโครงสร้างเดิม

| ไฟล์ | ส่วนที่ดูแล |
| --- | --- |
| `index.html` | หน้าเริ่มเกม หน้าสร้างตัวละคร และ UI |
| `game.js` | การเดิน แอนิเมชันตัวละคร แผนที่ การชน และเหมือง |
| `map.js` | ตรวจและโหลดข้อมูลแผนที่เมือง จัดการการแก้ไข นำเข้า และส่งออก |
| `maps/town.js` | ข้อมูลแผนที่เริ่มต้น พิกัดอาคาร ถนน ต้นไม้ สวน และจุดเกิดรถ |
| `npc.js` | เพื่อนบ้าน สัตว์ เหตุการณ์ และการจำผู้เล่น |
| `life.js` | ค่าสถานะ อาหาร กระเป๋า ร้านค้า และการบันทึก |
| `audio.js` | เสียงบรรยากาศ เอฟเฟกต์ และเสียงฝีเท้าตามพื้น |
| `multiplayer.js` | สร้างหรือเข้าห้อง ซิงก์ผู้เล่น แชต และเสียงพูด |
| `assets/` | ภาพไอคอนเกมและไฟล์เสียงฝีเท้า |

ใช้ WASD, ลูกศร หรือจอยบนจอเพื่อเดิน กด Shift หรือปุ่ม 🏃 ค้างเพื่อวิ่ง กด E เพื่อใช้งาน และ I เพื่อเปิดกระเป๋า ปุ่ม ♪ เปิดหรือปิดเสียงเกมแยกจากเสียงแชต

## สวนหลังบ้าน

- ออกจากบ้านแล้วอ้อมทางขวาเข้าประตูสวน มีแปลงมะเขือเทศ 20 แปลง ปลูก รดน้ำ และรอประมาณ 16 วินาทีก่อนเก็บ
- ที่โต๊ะจัดการสวน จ้างมะปราง 10 เหรียญเพื่อปลูก รดน้ำ และเก็บผลสุกใส่ลัง เธอใช้เมล็ดในกระเป๋า ปิดการปลูกและรดน้ำอัตโนมัติได้หากต้องการให้เก็บเกี่ยวอย่างเดียว
- ตั้งส่งอัตโนมัติหรือกด **ส่งไปขาย** ร้านจ่าย 4 เหรียญต่อลูกเมื่อของไปถึง เมนูสวนจะแสดงว่ามะปรางกำลังทำอะไรหรือรออะไร
- เดินไปที่ประตูร้านหน้าบ้านเพื่อซื้อเมล็ดเพิ่มหรือขายมะเขือเทศในกระเป๋าด้วยตนเอง
- เดินไปที่ช่องจอดหน้าโรงรถทางซ้ายของบ้านแล้วกด E เพื่อเลือกรถ รถจะออกที่ช่องจอดนั้น
- รถยนต์และมอเตอร์ไซค์มีเสียงเครื่องตามความเร็ว จักรยานมีเสียงล้อ ปิดได้จากปุ่ม ♪ เสียงเกม

## แก้ไขและบันทึกแผนที่เมือง

1. กด **แผนที่** ในเกมเพื่อเปิดข้อมูลปัจจุบัน แก้ข้อมูลในช่อง หรือเลือกไฟล์ `town.json` / `town.js` ที่บันทึกไว้
2. กด **ใช้แผนที่นี้** เพื่อบันทึกลงในเบราว์เซอร์และเปิดเกมใหม่ หรือกด **บันทึก town.json** เพื่อเก็บไฟล์ไว้เปิดภายหลัง
3. หากต้องการตั้งแผนที่เริ่มต้นสำหรับคนอื่น ให้กด **บันทึก town.js** แล้วนำไฟล์ไปวางแทน `maps/town.js` ผู้เล่นที่มีแผนที่บันทึกไว้ในเบราว์เซอร์สามารถกด **ใช้แผนที่เริ่มต้น** เพื่อโหลดไฟล์นี้

`landmarks` มีบ้าน ร้าน โรงรถ และจุดเข้าออก `neighborhood` มีทางเดิน อาคาร ต้นไม้ และถนน `backyard` มีรั้ว แปลง และจุดผ่านของคนส่งของ หน่วยพิกัดเป็นพิกเซลในโลกเกม โดย x เพิ่มไปทางขวาและ y เพิ่มลงด้านล่าง คง `id` แปลงเดิมไว้ถ้าต้องการใช้ข้อมูลต้นที่ปลูกไว้ แผนที่ไฟล์นี้ใช้กับเมืองกลางแจ้ง ส่วนห้องในบ้านและเหมืองใช้ผังเดิมของเกม

เมื่อตั้งห้องออนไลน์ ผู้เล่นควรเปิดแผนที่เดียวกันเพื่อให้ตำแหน่งตรงกัน

## เมืองเติบโตเอง

- เมื่อเดินออกมาในเมือง ระบบจะเลือกแปลงว่างใกล้ผู้เล่นและทยอยสร้างบ้าน โรงช่าง และตลาด ใช้เวลาก่อสร้างประมาณ 13 วินาทีต่อแห่ง อาคารที่สร้างเสร็จจะถูกบันทึกแยกตามแผนที่ในเบราว์เซอร์
- มีเพื่อนบ้านประจำแผนที่ 16 คนตอนกลางวันและ 3 คนตอนกลางคืน คนงานในสวน คนขาย และลูกค้าในกิจกรรมยังทำงานตามเดิม
- ค่า `openLayout` ใน `maps/town.js` ลดอาคารที่สร้างอัตโนมัติในย่านใหญ่และลดต้นไม้รอบละแวกบ้านเพื่อเปิดพื้นที่เดิน

หากเล่นกับเพื่อน ให้อัปโหลดไฟล์ในโฟลเดอร์เกมขึ้นเว็บ HTTPS แล้วแชร์ลิงก์ห้องจากเมนู «ห้องออนไลน์» เกมโหลด PeerJS เมื่อเริ่มเชื่อมต่อ ส่วนข้อมูลตัวละครและความสัมพันธ์บันทึกในเบราว์เซอร์ที่เล่น
