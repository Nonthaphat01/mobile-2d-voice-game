# Background music for My Little Neighborhood V5

The game expects two audio files in this directory:

1. `track-1.mp3` — ข้ามเส้นนี้ไปด้วยกันไหม
2. `track-2.mp3` — พรุ่งนี้ยังมี

Play sequence: track-1, track-2, repeat. Music plays at 20% volume, ducking to 8% while another player talks. Playback starts on a user Join/Play gesture.

**Important:** Only publish audio files here if you own the rights or have permission to distribute them publicly. GitHub Pages is a public website. The source MP3 files are not included in this repository until uploaded separately.
